Session setup

Connect Gemini

A blank cookies.json file is included in the project folder. Cryox Drive reads it locally and never sends the cookie export to its own API clients.

1
Export Gemini cookies as JSON

The export must contain __Secure-1PSID and __Secure-1PSIDTS.

2
Replace the contents of cookies.json

Open cookies.json in the project root, paste the complete exported JSON, and save the file.

3
Check the connection

No import command is required. The session is reloaded when you check the connection.

Treat Gemini session cookies like a password. Never commit them, post them in an issue, or include them in screenshots.
